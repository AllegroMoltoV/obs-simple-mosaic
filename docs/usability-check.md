# 使い心地の確認の手順

## 目的

シンプルモザイクを OBS Studio で実際に使い、日常の配信で使いやすいかを確かめます。境界値のような厳密な動作の確認は、統合テストで済ませています。ここで見たいのは、範囲の合わせやすさ、スライダーの扱いやすさ、既定値の妥当性、項目名の分かりやすさです。

## 準備

確認の前に、Claude Code がビルドした Windows 版を `%PROGRAMDATA%\obs-studio\plugins\simple-mosaic\` に導入し、OBS Studio 33.0.1 で読み込まれることを確かめます。ほかの Claude Code のセッションが OBS Studio を使っていないことを、導入の前に確かめてください。

## 手順

1. 映像キャプチャデバイスなどのソースを右クリックし、フィルターを開きます。映像フィルターの追加から「シンプルモザイク」を選びます。付けた直後に、ソースの全体がモザイクになることを見てください。
2. 「範囲の X」「範囲の Y」「範囲の幅」「範囲の高さ」のスライダーを動かし、隠したい場所に範囲を合わせます。
3. 「マスの大きさ」を変え、粗さを調整します。既定は 16 px です。
4. 複数のレイヤーをグループにまとめ、グループにフィルターを付けます。グループの中のレイヤーをまとめてモザイクにできることを見てください。グループの外に置いたレイヤーには、モザイクがかかりません。

## 伺いたいこと

次の 5 点について、感じたことを自由に書いてください。

- 範囲の合わせやすさ
- スライダーの刻みと範囲の扱いやすさ
- 既定のマスの大きさ (16 px) の妥当性
- 項目名の分かりやすさ
- そのほか気になったこと

## 終了後

OBS Studio を終了してから、Claude Code に知らせてください。受け取った感想は一覧にし、対応案を添えて確認をお願いします。
